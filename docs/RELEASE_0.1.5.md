# DSH协作助手 0.1.5 / DSH Collaborator 0.1.5

帮助 DeepSeek Harness 先建立共同理解，再在交流中推进项目。包含领域全貌介绍、相关成果检索、用户起点与具体困惑记录、路线比较和持续协作提醒。

Help DeepSeek Harness build shared understanding and move projects forward through conversation: domain orientation, relevant references, feedback-based understanding, explained recommendations, and communication reminders.

## 安装 / Installation

1. 下载 `dsh-collaborator-0.1.5.tgz`，不用解压。Download the `.tgz` file and leave it compressed.
2. 在 DSH“插件 → 添加插件”中粘贴文件的完整本地路径，安装并启用。In DSH, open Plugins → Add plugin, paste the absolute local path, install, and enable.
3. 完整退出并重新打开 DSH，新建会话输入 `/collaborate status`，确认版本为 0.1.5。Fully quit and reopen DSH; check `/collaborate status` in a new session.

支持 DSH 0.2.2 预发布版；rc.1 和 rc.3 两套运行时各 20 项测试通过。Requires a DSH 0.2.2 prerelease; all 20 tests passed on each of rc.1 and rc.3.

安装包沿用已验证的原始 0.1.5 文件，本次未修改运行代码。This release uses the original verified 0.1.5 package without changing runtime code.
